# audit/ — verification tools

Everything here is read-only against the site and outside the app: no file in this folder is
imported by `src/`, and the project's own `package.json` is untouched. `audit/tools/` is its own
package with one dependency, `playwright-core`, resolving a Chromium from the local
`ms-playwright` cache.

## Run

The built preview must be answering on `http://127.0.0.1:4174/` (or set `DD_URL`):

```bash
npm run build
npx vite preview --port 4174 --host 127.0.0.1
node audit/tools/responsive.mjs
```

## The checks that matter

| Tool | What it proves |
| --- | --- |
| `responsive.mjs` | every route × width: overflow, content escaping the viewport, clipped headings, broken images, footer geometry |
| `verify.mjs` | route loads, pending plates, console errors |
| `qa.mjs` | section-level geometry, marquee speed cap |
| `a11y.mjs` | contrast, landmarks, labels, focus targets |
| `team-footer.mjs` | team 3/2/1 grid and the three footer groups at twelve widths |
| `testimonials.mjs` | published cards, 3/2/1 columns, type floors, hover pause, reduced motion |
| `pillars.mjs` | manifesto fan ≥1024, snap strip below, tap and page-scroll |
| `pillar-text.mjs` | no card copy covered by its neighbour |
| `workstack.mjs` | selected-work stack and its static fallback |
| `study-shot.mjs` | case-study image rails on a phone, grids on a laptop |
| `final-metrics.mjs` | the measured table quoted in `docs/` |

`capture.mjs`, `perf.mjs`, `case-perf.mjs`, `cta.mjs`, `layout.mjs`, `studies.mjs`, `flora.mjs`,
`record-flora.mjs`, `services.mjs`, `hero-audio.mjs`, `final-check.mjs`, `vp.mjs`, `spot.mjs` and
`sheets.mjs` are the older state captures and the image-sheet pipeline; they run on demand and
write into `audit/frames/` or `public/images/`.

## Outputs

Screenshots and JSON dumps are regenerated by running a tool; they are not committed and were
cleared in the 2026-11-24 cleanup along with the frames contact sheet. `REPORT.md` and
`manifest.json` are kept as the written record of the 2026-11-18 pass; their image references are
historical.
